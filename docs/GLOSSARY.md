# Domain vocabulary

| Term | Meaning |
|---|---|
| Workspace | A knowledge base with its own access permissions and documents. |
| Managed workspace | A workspace whose content changes are controlled by Traceleaf. |
| External folder | An explicitly authorized collection that Traceleaf may read but cannot modify in v1. |
| Source | Material supplied as evidence; importing it does not make every claim validated knowledge. |
| Document | A note with a stable identity across revisions and moves. |
| Revision | An immutable record of a document's content at a point in its history. |
| Proposal | A suggested creation or update of one document, or a justified no-change result. |
| Approval | A person's authorization of a specific proposal version against a specific base revision. |

These are planned domain concepts. M0 implements infrastructure, not these entities.
